# Tournées Calendriers – Amicale SP Volvic

Version V8 connectée au projet Supabase de l'Amicale.

## Mise en ligne GitHub Pages
Déposer index.html, app.js, manifest.json et sw.js à la racine du dépôt. Dans GitHub : Settings > Pages > Deploy from a branch > main > /(root) > Save.

## Sécurité
Le dépôt ne contient que la clé publique Supabase. Ne jamais y ajouter de clé service_role. Les accès aux données sont protégés par les politiques RLS de Supabase.
